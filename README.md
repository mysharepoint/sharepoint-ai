# SharePoint AI

`sharepoint-ai` is a practical collection of examples, tool references, skills, and working notes for using AI with Microsoft SharePoint, Copilot in SharePoint, and Microsoft 365 content operations.

The current focus of this repository is the **Copilot in SharePoint Agent ToolBox**: a structured Markdown reference for SharePoint and Microsoft 365 agent capabilities.
