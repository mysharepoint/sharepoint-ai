# create_chart

## Purpose (EN)

Creates charts from data – bar, line, pie, scatter – no code needed.

## Zweck (DE)

Erstellt Diagramme aus Daten – Balken, Linien, Kreis, Scatter – ohne Code.

## Use Case (EN)

Visualize data – e.g. deployment numbers as bar chart.

## Anwendung (DE)

Daten visuell aufbereiten – z.B. Ausbauzahlen als Balkendiagramm.

## Example (EN)

> Create a bar chart of wind energy capacity by region.

## Beispiel (DE)

> Erstelle ein Balkendiagramm der Windenergie-Kapazität nach Regionen.

## Prompt Template (EN)

> Create a [chart type] chart from [data source].

## Prompt-Vorlage (DE)

> Erstelle ein [Diagrammtyp]-Diagramm aus [Datenquelle].

## Key Parameters

`charts[] (type, data/dataPath, title), dataRef`

## Prerequisite

Daten müssen vorliegen (z.B. aus execute_code oder list_items)
