# copy_items

## Purpose (EN)

Copies files or folders to a destination folder.

## Zweck (DE)

Kopiert Dateien oder Ordner in einen Zielordner.

## Use Case (EN)

Duplicate files, distribute templates, or create backups.

## Anwendung (DE)

Dateien duplizieren, Vorlagen verteilen oder Sicherungskopien erstellen.

## Example (EN)

> Copy Briefing.docx to the Archive folder.

## Beispiel (DE)

> Kopiere die Datei Briefing.docx in den Ordner Archiv.

## Prompt Template (EN)

> Copy [file/folder] to [destination folder].

## Prompt-Vorlage (DE)

> Kopiere [Datei/Ordner] nach [Zielordner].

## Key Parameters

`Quell-/Zielpfade`

## Prerequisite

Keine
