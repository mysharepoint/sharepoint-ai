# create_folder

## Purpose (EN)

Creates one or more folders in a document library, optionally with color.

## Zweck (DE)

Erstellt einen oder mehrere Ordner in einer Dokumentbibliothek, optional mit Farbe.

## Use Case (EN)

Create folder structures – e.g. a new folder for a campaign.

## Anwendung (DE)

Ordnerstrukturen anlegen – z.B. einen neuen Ordner für eine Kampagne.

## Example (EN)

> Create a blue folder called Campaign 2026 in the document library.

## Beispiel (DE)

> Erstelle einen blauen Ordner namens Kampagne 2026 in der Dokumentbibliothek.

## Prompt Template (EN)

> Create a [color] folder named [name] in [library/path].

## Prompt-Vorlage (DE)

> Erstelle einen [Farbe] Ordner namens [Name] in [Bibliothek/Pfad].

## Key Parameters

`listFullUrl, folders[] (name, relativeFolderPath, folderColor)`

## Prerequisite

Keine
