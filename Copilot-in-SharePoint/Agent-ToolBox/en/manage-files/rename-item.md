# rename_item

## Purpose (EN)

Renames files or folders in a document library.

## Zweck (DE)

Benennt Dateien oder Ordner in einer Dokumentbibliothek um.

## Use Case (EN)

Rename files – e.g. change temporary name to final title.

## Anwendung (DE)

Dateien umbenennen – z.B. temporären Namen in finalen Titel ändern.

## Example (EN)

> Rename Draft_v1.docx to PressRelease_Final.docx.

## Beispiel (DE)

> Benenne die Datei Draft_v1.docx in Pressemitteilung_Final.docx um.

## Prompt Template (EN)

> Rename [filename] to [new name].

## Prompt-Vorlage (DE)

> Benenne [Dateiname] um in [neuer Name].

## Key Parameters

`listFullUrl, alte/neue Namen`

## Prerequisite

Keine
