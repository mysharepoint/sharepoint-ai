# set_folder_color

## Purpose (EN)

Sets or changes the color of one or more folders.

## Zweck (DE)

Setzt oder ändert die Farbe eines oder mehrerer Ordner.

## Use Case (EN)

Make folders visually distinguishable – e.g. mark urgent folders red.

## Anwendung (DE)

Ordner visuell unterscheidbar machen – z.B. dringende Ordner rot markieren.

## Example (EN)

> Set the Urgent folder color to red.

## Beispiel (DE)

> Setze den Ordner Dringend auf die Farbe Rot.

## Prompt Template (EN)

> Change the color of folder [name] to [color].

## Prompt-Vorlage (DE)

> Ändere die Farbe von Ordner [Name] auf [Farbe].

## Key Parameters

`Bibliothek, Ordner, Farbe`

## Prerequisite

Keine
