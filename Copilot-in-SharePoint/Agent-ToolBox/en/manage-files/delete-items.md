# delete_items

## Purpose (EN)

Deletes files or folders from a document library (recycle bin).

## Zweck (DE)

Löscht Dateien oder Ordner aus einer Dokumentbibliothek (Papierkorb).

## Use Case (EN)

Remove outdated or incorrect files.

## Anwendung (DE)

Veraltete oder fehlerhafte Dateien entfernen.

## Example (EN)

> Delete Entwurf_alt.docx from the document library.

## Beispiel (DE)

> Lösche die Datei Entwurf_alt.docx aus der Dokumentbibliothek.

## Prompt Template (EN)

> Delete [file/folder] from [library].

## Prompt-Vorlage (DE)

> Lösche [Datei/Ordner] aus [Bibliothek].

## Key Parameters

`listFullUrl, Elemente`

## Prerequisite

Keine
