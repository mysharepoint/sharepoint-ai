# move_items

## Purpose (EN)

Moves files or folders to a destination folder.

## Zweck (DE)

Verschiebt Dateien oder Ordner in einen Zielordner.

## Use Case (EN)

Reorganize files – e.g. move finished documents to archive.

## Anwendung (DE)

Dateien reorganisieren – z.B. fertige Dokumente ins Archiv verschieben.

## Example (EN)

> Move all PDF files to the Press Releases folder.

## Beispiel (DE)

> Verschiebe alle PDF-Dateien in den Ordner Pressemitteilungen.

## Prompt Template (EN)

> Move [file/folder] to [destination folder].

## Prompt-Vorlage (DE)

> Verschiebe [Datei/Ordner] nach [Zielordner].

## Key Parameters

`Quell-/Zielpfade`

## Prerequisite

Keine
