# add_shortcut

## Purpose (EN)

Creates shortcuts to files or folders across source-to-destination pairs.

## Zweck (DE)

Erstellt Verknüpfungen (Shortcuts) zu Dateien oder Ordnern.

## Use Case (EN)

Make files accessible in multiple locations without copying.

## Anwendung (DE)

Dateien an mehreren Stellen zugänglich machen, ohne sie zu kopieren.

## Example (EN)

> Create a shortcut to Styleguide.pdf in the Communications folder.

## Beispiel (DE)

> Erstelle eine Verknüpfung zur Datei Styleguide.pdf im Ordner Kommunikation.

## Prompt Template (EN)

> Create a shortcut to [file] in [destination folder].

## Prompt-Vorlage (DE)

> Erstelle eine Verknüpfung zu [Datei] in [Zielordner].

## Key Parameters

`Quell-/Zielpaare`

## Prerequisite

Keine
