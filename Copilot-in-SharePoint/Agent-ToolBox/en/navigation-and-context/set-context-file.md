# set_context_file

## Purpose (EN)

Creates or updates the SHAREPOINT.md context file for the site.

## Zweck (DE)

Erstellt oder aktualisiert die SHAREPOINT.md-Kontextdatei der Site.

## Use Case (EN)

Customize the site context for the agent – e.g. add new references.

## Anwendung (DE)

Den Site-Kontext für den Agenten anpassen – z.B. neue Referenzen hinzufügen.

## Example (EN)

> Update SharePoint.md with the new speaker profiles.

## Beispiel (DE)

> Aktualisiere die SharePoint.md mit den neuen Sprecherprofilen.

## Prompt Template (EN)

> Update the SharePoint.md with [content].

## Prompt-Vorlage (DE)

> Aktualisiere die SharePoint.md mit [Inhalt].

## Key Parameters

`Neuer Inhalt der Kontextdatei`
