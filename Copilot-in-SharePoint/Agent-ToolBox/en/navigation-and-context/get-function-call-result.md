# get_function_call_result

## Purpose (EN)

Retrieves the full output of a previous function call by reference ID.

## Zweck (DE)

Ruft die vollständige Ausgabe eines vorherigen Funktionsaufrufs ab.

## Use Case (EN)

Retrieve results that were only partially returned in a previous call.

## Anwendung (DE)

Ergebnisse abrufen, die bei einem vorherigen Aufruf nur teilweise zurückgegeben wurden.

## Example (EN)

> Show the full result of the last call.

## Beispiel (DE)

> Zeige das vollständige Ergebnis des letzten Aufrufs.

## Prompt Template (EN)

> Show the full result of [reference ID].

## Prompt-Vorlage (DE)

> Zeige das vollständige Ergebnis von [Referenz-ID].

## Key Parameters

`Referenz-ID`

## Prerequisite

Vorheriger Funktionsaufruf
