# get_current_list_or_library

## Purpose (EN)

Retrieves info about the current list or library the user is viewing.

## Zweck (DE)

Ruft Informationen zur aktuellen Liste oder Bibliothek ab.

## Use Case (EN)

Get context information for subsequent actions.

## Anwendung (DE)

Kontextinformationen ermitteln für nachfolgende Aktionen.
