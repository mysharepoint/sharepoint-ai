# create_form

## Purpose (EN)

Creates a new form on a SharePoint list with fields, theme, and notifications.

## Zweck (DE)

Erstellt ein neues Formular für eine SharePoint-Liste mit Feldern, Design und Benachrichtigungen.

## Use Case (EN)

Create input forms for lists – e.g. a form to submit new text blocks.

## Anwendung (DE)

Eingabeformulare für Listen erstellen – z.B. ein Formular zur Einreichung neuer Textbausteine.

## Example (EN)

> Create a form for the BWEC-TB-QUOTE list to submit new text blocks.

## Beispiel (DE)

> Erstelle ein Formular für die BWEC-TB-QUOTE-Liste zur Einreichung neuer Bausteine.

## Prompt Template (EN)

> Create a form for [list] with [fields/theme].

## Prompt-Vorlage (DE)

> Erstelle ein Formular für [Liste] mit [Feldern/Design].

## Key Parameters

`Liste, Felder, Design, Benachrichtigungen`

## Prerequisite

get_list_schema
