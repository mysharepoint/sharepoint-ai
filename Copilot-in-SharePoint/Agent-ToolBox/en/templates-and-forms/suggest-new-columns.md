# suggest_new_columns

## Purpose (EN)

Analyzes a library and suggests new columns.

## Zweck (DE)

Analysiert eine Bibliothek und schlägt neue Spalten vor.

## Use Case (EN)

Identify metadata improvements – which columns would improve organization.

## Anwendung (DE)

Metadaten-Verbesserungen identifizieren – welche Spalten die Organisation verbessern.

## Example (EN)

> What additional columns would improve the document library

## Beispiel (DE)

> Welche zusätzlichen Spalten würden die Dokumentbibliothek verbessern

## Prompt Template (EN)

> Suggest new columns for [library].

## Prompt-Vorlage (DE)

> Schlage neue Spalten für [Bibliothek] vor.
