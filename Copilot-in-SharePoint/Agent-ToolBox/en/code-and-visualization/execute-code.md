# execute_code

## Purpose (EN)

Executes sandboxed JavaScript – calculations, data transformation, Canvas images, HTML reports.

## Zweck (DE)

Führt sandboxed JavaScript aus – Berechnungen, Datentransformation, Canvas-Bilder, HTML-Reports.

## Use Case (EN)

Calculations, data transformation, complex logic, HTML dashboards or Canvas graphics.

## Anwendung (DE)

Berechnungen, Daten transformieren, komplexe Logik, HTML-Dashboards oder Canvas-Grafiken.
