# get_rules

## Purpose (EN)

Retrieves all SharePoint rules defined for a list.

## Zweck (DE)

Ruft alle SharePoint-Regeln ab, die für eine Liste definiert sind.

## Use Case (EN)

Review and manage existing automation rules.

## Anwendung (DE)

Bestehende Automatisierungsregeln prüfen und verwalten.

## Example (EN)

> Show me all rules of the BWEC-TB-QUOTE list.

## Beispiel (DE)

> Zeige mir alle Regeln der Liste BWEC-TB-QUOTE.

## Prompt Template (EN)

> Show all rules of the list [list name].

## Prompt-Vorlage (DE)

> Zeige alle Regeln der Liste [Listenname].

## Key Parameters

`Liste`

## Prerequisite

Keine
