# configure_quick_step_columns

## Purpose (EN)

Creates, updates, or deletes quick step columns in a list.

## Zweck (DE)

Erstellt, aktualisiert oder löscht Quick-Step-Spalten in einer Liste.

## Use Case (EN)

Configure quick step columns for one-click actions in list views.

## Anwendung (DE)

Quick-Step-Spalten konfigurieren für Ein-Klick-Aktionen in Listenansichten.

## Example (EN)

> Create a quick step column Action with options Approve and Reject.

## Beispiel (DE)

> Erstelle eine Quick-Step-Spalte Aktion mit den Optionen Freigeben und Ablehnen.

## Prompt Template (EN)

> Create a quick step column [name] in [list] with [options].

## Prompt-Vorlage (DE)

> Erstelle eine Quick-Step-Spalte [Name] in [Liste] mit [Optionen].

## Key Parameters

`Liste, Spaltendefinition`

## Prerequisite

get_list_schema
