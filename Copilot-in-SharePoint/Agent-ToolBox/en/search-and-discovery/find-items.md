# find_items

## Purpose (EN)

Finds files by name, extension, or pattern. Like Unix find.

## Zweck (DE)

Sucht Dateien nach Name, Erweiterung oder Muster. Wie Unix find.

## Use Case (EN)

Find files in libraries – e.g. all PDFs or files with 'press release' in the name.

## Anwendung (DE)

Dateien in Bibliotheken finden – z.B. alle PDFs oder Dateien mit 'Pressemitteilung' im Namen.

## Example (EN)

> Find all Word documents in the document library.

## Beispiel (DE)

> Finde alle Word-Dokumente in der Dokumentbibliothek.

## Prompt Template (EN)

> Find all [file type] files in [library/folder].

## Prompt-Vorlage (DE)

> Finde alle [Dateityp]-Dateien in [Bibliothek/Ordner].

## Key Parameters

`listId, pattern (*.docx), itemType, contentHints[], searchMode, searchScope`

## Prerequisite

Keine
