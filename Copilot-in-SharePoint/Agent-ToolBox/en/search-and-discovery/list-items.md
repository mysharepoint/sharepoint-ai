# list_items

## Purpose (EN)

Lists, counts, or filters items in a list, library, or folder.

## Zweck (DE)

Listet, zählt oder filtert Elemente in einer Liste, Bibliothek oder einem Ordner.

## Use Case (EN)

List contents – e.g. all files in a folder or filtered list entries.

## Anwendung (DE)

Inhalte auflisten – z.B. alle Dateien in einem Ordner oder gefilterte Listeneinträge.

## Example (EN)

> Show all approved text blocks in the BWEC-TB-QUOTE list.

## Beispiel (DE)

> Zeige alle genehmigten Textbausteine in der BWEC-TB-QUOTE-Liste.

## Prompt Template (EN)

> Show all [items] in [list/library] with [filter].

## Prompt-Vorlage (DE)

> Zeige alle [Elemente] in [Liste/Bibliothek] mit [Filter].

## Key Parameters

`listId, rowLimit, filter (CAML), viewFields[], itemType, folderServerRelativeUrl`

Keine
