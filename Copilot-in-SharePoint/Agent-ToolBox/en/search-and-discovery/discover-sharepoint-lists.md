# discover_sharepoint_lists

## Purpose (EN)

Discovers all lists and document libraries in a SharePoint site.

## Zweck (DE)

Entdeckt alle Listen und Dokumentbibliotheken in einer SharePoint-Site.

## Use Case (EN)

Get an overview of existing lists and libraries.

## Anwendung (DE)

Überblick über vorhandene Listen und Bibliotheken gewinnen.

## Example (EN)

> What lists and libraries exist on this site

## Beispiel (DE)

> Welche Listen und Bibliotheken gibt es auf dieser Site

## Prompt Template (EN)

> Show all lists and libraries on [site].

## Prompt-Vorlage (DE)

> Zeige alle Listen und Bibliotheken auf [Site].
