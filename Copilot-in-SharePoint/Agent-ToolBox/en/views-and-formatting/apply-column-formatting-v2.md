# apply_column_formatting_v2

## Purpose (EN)

Applies column-level formatting JSON to a list field – pills, icons, data bars.

## Zweck (DE)

Wendet spaltenbasiertes JSON-Formatting auf ein Listenfeld an – Pillen, Icons, Datenbalken.

## Use Case (EN)

Visual customization of individual columns – e.g. colored status pills.

## Anwendung (DE)

Visuelle Anpassungen einzelner Spalten – z.B. farbige Status-Pillen.

## Example (EN)

> Format the Status column with colored pills: green for Approved, yellow for Draft.

## Beispiel (DE)

> Formatiere die Spalte Status mit farbigen Pillen: Grün für Genehmigt, Gelb für Entwurf.

## Prompt Template (EN)

> Format the column [column] in [list] with [formatting].

## Prompt-Vorlage (DE)

> Formatiere die Spalte [Spalte] in [Liste] mit [Formatierung].

## Key Parameters

`Liste, Feld, Formatting-JSON`

## Prerequisite

get_list_schema (Feldnamen und aktuelle Formatierung)
