# delete_view

## Purpose (EN)

Permanently deletes one or more views from a SharePoint list.

## Zweck (DE)

Löscht eine oder mehrere Ansichten dauerhaft aus einer SharePoint-Liste.

## Use Case (EN)

Clean up unnecessary or outdated views.

## Anwendung (DE)

Überflüssige oder veraltete Ansichten aufräumen.

## Example (EN)

> Delete the view Old Overview from the list.

## Beispiel (DE)

> Lösche die Ansicht Alte Übersicht aus der Liste.

## Prompt Template (EN)

> Delete the view [view name] from [list].

## Prompt-Vorlage (DE)

> Lösche die Ansicht [Ansichtsname] aus [Liste].

## Key Parameters

`Liste, Ansichts-ID(s)`

## Prerequisite

get_views_of_list (liefert IDs)
