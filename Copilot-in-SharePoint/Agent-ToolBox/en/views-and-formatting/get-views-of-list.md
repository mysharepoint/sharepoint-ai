# get_views_of_list

## Purpose (EN)

Retrieves all views of a list or library.

## Zweck (DE)

Ruft alle Ansichten einer Liste oder Bibliothek ab.

## Use Case (EN)

Get an overview of existing views.

## Anwendung (DE)

Überblick über vorhandene Ansichten gewinnen.

## Example (EN)

> What views does the BWEC-TB-QUOTE list have

## Beispiel (DE)

> Welche Ansichten hat die Liste BWEC-TB-QUOTE

## Prompt Template (EN)

## Prompt-Vorlage (DE)
