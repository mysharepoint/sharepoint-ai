# preview_view_changes

## Purpose (EN)

Previews how a list would look after applying view changes.

## Zweck (DE)

Zeigt eine Vorschau, wie eine Liste nach View-Änderungen aussehen würde.

## Use Case (EN)

Test view changes before applying them.

## Anwendung (DE)

Änderungen an Ansichten testen, bevor sie angewendet werden.

## Example (EN)

> Show a preview of the list grouped by Status.

## Beispiel (DE)

> Zeige eine Vorschau, wie die Liste aussieht wenn ich nach Status gruppiere.

## Prompt Template (EN)

> Show a preview of the view [view] with [changes].

## Prompt-Vorlage (DE)

> Zeige eine Vorschau der Ansicht [Ansicht] mit [Änderungen].

## Key Parameters

`Liste, Ansicht, vorgeschlagene Änderungen`

get_view_definition
