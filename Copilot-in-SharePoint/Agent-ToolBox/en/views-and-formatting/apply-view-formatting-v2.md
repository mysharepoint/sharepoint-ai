# apply_view_formatting_v2

## Purpose (EN)

Applies view-level formatting JSON to a list view.

## Zweck (DE)

Wendet ansichtsbasiertes JSON-Formatting auf eine Listenansicht an.

## Use Case (EN)

Style entire views – e.g. highlight rows with colors.

## Anwendung (DE)

Gestaltung ganzer Ansichten – z.B. Zeilen farbig hervorheben.

## Example (EN)

> Highlight all rows with status Urgent in red in the default view.

## Beispiel (DE)

> Hebe alle Zeilen mit Status Dringend in der Standardansicht rot hervor.

## Prompt Template (EN)

> Format the view [view] in [list] with [formatting].

## Prompt-Vorlage (DE)

> Formatiere die Ansicht [Ansicht] in [Liste] mit [Formatierung].

## Key Parameters

`Liste, Ansicht, Formatting-JSON`

## Prerequisite

get_views_of_list, get_view_definition
