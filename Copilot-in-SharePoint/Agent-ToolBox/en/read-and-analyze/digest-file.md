# digest_file

## Purpose (EN)

Summarizes and compares files using a specialized M365 file analysis agent.

## Zweck (DE)

Fasst Dateien zusammen und vergleicht sie mithilfe eines spezialisierten M365-Agenten.

## Use Case (EN)

Create quick summaries or compare multiple files by content.

## Anwendung (DE)

Schnelle Zusammenfassungen erstellen oder mehrere Dateien inhaltlich vergleichen.

## Example (EN)

> Summarize the key points from the PDF 2410.14681v1.pdf.

## Beispiel (DE)

> Fasse die wichtigsten Punkte aus dem PDF 2410.14681v1.pdf zusammen.
