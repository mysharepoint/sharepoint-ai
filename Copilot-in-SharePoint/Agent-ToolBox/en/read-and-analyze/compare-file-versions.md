# compare_file_versions

## Purpose (EN)

Analyzes changes in Word, PowerPoint, or Excel documents across versions.

## Zweck (DE)

Analysiert Änderungen in Word-, PowerPoint- oder Excel-Dokumenten über Versionen hinweg.

## Use Case (EN)

Track what changed between document versions.

## Anwendung (DE)

Nachvollziehen, was sich zwischen Dokumentversionen geändert hat.

## Example (EN)

> Compare the last two versions of Pressemitteilung.docx.

## Beispiel (DE)

> Vergleiche die letzten beiden Versionen der Datei Pressemitteilung.docx.

## Prompt Template (EN)

> Compare versions [from/to] of the file [filename].

## Prompt-Vorlage (DE)

> Vergleiche die Versionen [von/bis] der Datei [Dateiname].

`Dokument, Versionen`
