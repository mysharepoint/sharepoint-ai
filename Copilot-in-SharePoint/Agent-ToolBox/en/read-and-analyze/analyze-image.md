# analyze_image

## Purpose (EN)

Analyzes SharePoint/OneDrive images using AI vision (GPT-4o).

## Zweck (DE)

Analysiert Bilder in SharePoint/OneDrive mithilfe von KI-Vision (GPT-4o).

Describe image contents, extract text from screenshots, interpret charts or infographics.
