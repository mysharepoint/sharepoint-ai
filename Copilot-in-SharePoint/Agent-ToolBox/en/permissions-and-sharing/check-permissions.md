# check_permissions

## Purpose (EN)

Checks whether specified users have access to items.

## Zweck (DE)

Prüft, ob bestimmte Benutzer Zugriff auf Elemente haben.

## Use Case (EN)

Check who has access before sharing.

## Anwendung (DE)

Vor dem Teilen prüfen, wer Zugriff hat.

## Example (EN)

> Does Emma Collins have access to Pressemitteilung.docx

## Beispiel (DE)

> Hat Emma Collins Zugriff auf die Datei Pressemitteilung.docx

## Prompt Template (EN)

> Does [person] have access to [item] in [list/library]

## Prompt-Vorlage (DE)

> Hat [Person] Zugriff auf [Element] in [Liste/Bibliothek]

## Key Parameters

`Elemente, Benutzer`

## Prerequisite

Keine
