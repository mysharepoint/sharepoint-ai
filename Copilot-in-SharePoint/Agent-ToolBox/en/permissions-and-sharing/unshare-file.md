# unshare_file

## Purpose (EN)

Removes a user's access to a file.

## Zweck (DE)

Entfernt den Zugriff eines Benutzers auf eine Datei.

## Use Case (EN)

Revoke access – e.g. after collaboration is complete.

## Anwendung (DE)

Zugriff widerrufen – z.B. nach Abschluss einer Zusammenarbeit.

## Example (EN)

> Remove External-User's access to Pressemitteilung.docx.

## Beispiel (DE)

> Entferne den Zugriff von Extern-User auf Pressemitteilung.docx.

## Prompt Template (EN)

> Remove [person]'s access to [file].

## Prompt-Vorlage (DE)

> Entferne den Zugriff von [Person] auf [Datei].

## Key Parameters

`Datei, Benutzer`

## Prerequisite

Keine
