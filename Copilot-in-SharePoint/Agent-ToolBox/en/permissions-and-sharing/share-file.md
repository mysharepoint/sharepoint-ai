# share_file

## Purpose (EN)

Shares a file by creating a sharing link and sending an email notification.

## Zweck (DE)

Teilt eine Datei per Freigabelink und E-Mail-Benachrichtigung.

## Use Case (EN)

Share documents with colleagues.

## Anwendung (DE)

Dokumente mit Kolleginnen und Kollegen teilen.

## Example (EN)

> Share Briefing.docx with Emma Collins.

## Beispiel (DE)

> Teile die Datei Briefing.docx mit Emma Collins.

## Prompt Template (EN)

> Share [filename] with [person(s)].

## Prompt-Vorlage (DE)

> Teile [Dateiname] mit [Person(en)].

## Key Parameters

`Datei, Empfänger`

## Prerequisite

Keine
