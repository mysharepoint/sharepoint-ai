# delete_list_item

## Purpose (EN)

Deletes one or more items from a SharePoint list by item ID.

## Zweck (DE)

Löscht einen oder mehrere Einträge aus einer SharePoint-Liste nach Item-ID.

## Use Case (EN)

Remove individual list items.

## Anwendung (DE)

Einzelne Listeneinträge entfernen.

## Example (EN)

> Delete item 42 from the BWEC-TB-QUOTE list.

## Beispiel (DE)

> Lösche Eintrag 42 aus der Liste BWEC-TB-QUOTE.

## Prompt Template (EN)

> Delete item [ID] from list [list name].

## Prompt-Vorlage (DE)

> Lösche Eintrag [ID] aus der Liste [Listenname].

## Key Parameters

`Liste, Item-ID(s)`

## Prerequisite

list_items (um IDs zu ermitteln)
