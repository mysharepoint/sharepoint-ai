# list_item_versions

## Purpose (EN)

Lists all versions of a list item – editor, timestamp, size.

## Zweck (DE)

Listet alle Versionen eines Listeneintrags auf – Bearbeiter, Zeitstempel, Größe.

## Use Case (EN)

Track change history – e.g. who last edited a text block.

## Anwendung (DE)

Änderungshistorie nachvollziehen – z.B. wer einen Textbaustein zuletzt bearbeitet hat.

## Example (EN)

> Show me the version history of item 10.

## Beispiel (DE)

> Zeige mir die Versionshistorie von Eintrag 10.

## Prompt Template (EN)

> Show versions of item [ID] in [list].

## Prompt-Vorlage (DE)

> Zeige die Versionen von Eintrag [ID] in [Liste].

## Key Parameters

`Liste, Item-ID(s)`

## Prerequisite

Keine
