# create_skill

## Purpose (EN)

Creates or updates a reusable skill file in the AgentAssets library.

## Zweck (DE)

Erstellt oder aktualisiert eine wiederverwendbare Skill-Datei in AgentAssets.

## Use Case (EN)

Create new skills for the agent or update existing ones.

## Anwendung (DE)

Neue Skills für den Agenten erstellen oder bestehende aktualisieren.

## Example (EN)

> Create a new skill named fact-check with the following content.

## Beispiel (DE)

> Erstelle einen neuen Skill namens faktencheck mit folgendem Inhalt.

## Prompt Template (EN)

> Create a skill named [name] with [content].

## Prompt-Vorlage (DE)

> Erstelle einen Skill namens [Name] mit [Inhalt].

## Key Parameters

`Skill-Name, Inhalt`

## Prerequisite

Keine
