# load_skill

## Purpose (EN)

Loads a skill from AgentAssets/Skills and makes it available.

## Zweck (DE)

Lädt einen Skill aus AgentAssets/Skills und macht ihn verfügbar.

## Use Case (EN)

Activate a predefined workflow – e.g. press-statement or pembroke-comment.

## Anwendung (DE)

Einen vordefinierten Workflow aktivieren – z.B. presse-statement oder pembroke-kommentar.

## Example (EN)

> Load the skill press-statement.

## Beispiel (DE)

> Lade den Skill presse-statement.

## Prompt Template (EN)

> Load the skill [skill name].

## Prompt-Vorlage (DE)

> Lade den Skill [Skill-Name].

## Key Parameters

`Skill-Name`

## Prerequisite

Skill muss in AgentAssets/Skills existieren
