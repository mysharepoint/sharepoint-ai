# get_restoreable_lists

## Purpose (EN)

Retrieves deleted lists/libraries that can be restored.

## Zweck (DE)

Ruft gelöschte Listen/Bibliotheken ab, die wiederhergestellt werden können.

## Use Case (EN)

Identify accidentally deleted lists.

## Anwendung (DE)

Versehentlich gelöschte Listen identifizieren.

## Example (EN)

> Are there deleted lists in the recycle bin

## Beispiel (DE)

> Gibt es gelöschte Listen im Papierkorb

## Prompt Template (EN)

> Show restorable lists in the recycle bin.

## Prompt-Vorlage (DE)

> Zeige wiederherstellbare Listen im Papierkorb.

## Key Parameters

`Site`

Keine
