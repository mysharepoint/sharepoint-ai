# get_list_schema

## Purpose (EN)

Retrieves the complete schema of a list – fields, types, content types, item count.

## Zweck (DE)

Ruft das vollständige Schema einer Liste ab – Felder, Typen, Inhaltstypen, Elementanzahl.

## Use Case (EN)

Understand list structure – e.g. which columns exist and their data types.

## Anwendung (DE)

Listenstruktur verstehen – z.B. welche Spalten existieren und welche Datentypen.

## Example (EN)

> Show me the schema of the BWEC-TB-QUOTE list.

## Beispiel (DE)

> Zeige mir das Schema der Liste BWEC-TB-QUOTE.

## Prompt Template (EN)

> Show the schema / columns of the list [list name].

## Prompt-Vorlage (DE)

> Zeige das Schema / die Spalten der Liste [Listenname].

## Key Parameters

`listId, includeHidden, includeReadOnly, includeFormatter`

## Prerequisite

Keine
