# create_or_update_list

## Purpose (EN)

Creates a new SharePoint list/library or updates an existing one.

## Zweck (DE)

Erstellt eine neue SharePoint-Liste/Bibliothek oder aktualisiert eine bestehende.

## Use Case (EN)

Create new lists or extend existing ones with columns and views.

## Anwendung (DE)

Neue Listen anlegen oder bestehende um Spalten und Ansichten erweitern.

## Example (EN)

> Create a new list called Copilot Toolbox with columns Tool Name and Category.

## Beispiel (DE)

> Erstelle eine neue Liste namens Copilot Toolbox mit den Spalten Tool-Name und Kategorie.

## Prompt Template (EN)

> Create a list named [name] with columns [columns].

## Prompt-Vorlage (DE)

> Erstelle eine Liste namens [Name] mit den Spalten [Spalten].

## Key Parameters

`listName, isNewList, columns[], views[], templateType, webUrl`

## Prerequisite

discover_sharepoint_lists (prüfen ob Name existiert)
