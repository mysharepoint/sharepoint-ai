# delete_list

## Purpose (EN)

Permanently deletes a SharePoint list or document library (recycle bin).

## Zweck (DE)

Löscht eine SharePoint-Liste oder Dokumentbibliothek dauerhaft (Papierkorb).

## Use Case (EN)

Remove lists or libraries that are no longer needed.

## Anwendung (DE)

Nicht mehr benötigte Listen oder Bibliotheken entfernen.

## Example (EN)

> Delete the list Test Drafts.

## Beispiel (DE)

> Lösche die Liste Test-Entwürfe.

## Prompt Template (EN)

> Delete the list [list name].

## Prompt-Vorlage (DE)

> Lösche die Liste [Listenname].

## Key Parameters

`Liste`

## Prerequisite

Keine
