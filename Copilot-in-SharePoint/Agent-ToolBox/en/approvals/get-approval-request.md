# get_approval_request

## Purpose (EN)

Gets approval request details for a specific list item.

## Zweck (DE)

Ruft Details zu einer Genehmigungsanfrage für ein Listenelement ab.

## Use Case (EN)

Check the status of a pending approval.

## Anwendung (DE)

Status einer laufenden Genehmigung prüfen.

## Example (EN)

> Show the approval status of item 15.

## Beispiel (DE)

> Zeige den Genehmigungsstatus von Eintrag 15.

## Prompt Template (EN)

> Show the approval status of [item] in [list].

## Prompt-Vorlage (DE)

> Zeige den Genehmigungsstatus von [Element] in [Liste].

## Key Parameters

`Liste, Item`

## Prerequisite

Keine
