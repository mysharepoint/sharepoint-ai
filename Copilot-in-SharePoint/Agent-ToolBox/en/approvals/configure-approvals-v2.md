# configure_approvals_v2

## Purpose (EN)

Configures modern approvals for a SharePoint list.

## Zweck (DE)

Konfiguriert moderne Genehmigungen für eine SharePoint-Liste.

## Use Case (EN)

Set up approval processes – so items are only marked approved after review.

## Anwendung (DE)

Freigabeprozesse einrichten – damit Einträge erst nach Genehmigung als freigegeben gelten.

## Example (EN)

> Enable approvals for the BWEC-TB-QUOTE list with Emma Collins as approver.

## Beispiel (DE)

> Aktiviere Genehmigungen für die Liste BWEC-TB-QUOTE mit Emma Collins als Genehmigerin.

## Prompt Template (EN)

> Enable approvals for [list] with [approver].

## Prompt-Vorlage (DE)

> Aktiviere Genehmigungen für [Liste] mit [Genehmiger].

## Key Parameters

`Liste, aktivieren/deaktivieren, Standard-Genehmiger`

Keine
