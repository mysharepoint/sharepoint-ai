# get_location_info

## Purpose (EN)

Resolves location names or addresses into SharePoint Location field format.

## Zweck (DE)

Löst Ortsnamen oder Adressen in das SharePoint-Location-Format auf.

## Use Case (EN)

Insert location data correctly into list items.

## Anwendung (DE)

Standortdaten korrekt in Listeneinträge einfügen.

## Example (EN)

> Resolve 14 King's Bench Walk, London for a location field.

## Beispiel (DE)

> Löse die Adresse 14 King's Bench Walk, London für ein Location-Feld auf.

## Prompt Template (EN)

> Resolve [address/place] for a location field.

## Prompt-Vorlage (DE)

> Löse [Adresse/Ort] für ein Location-Feld auf.

## Key Parameters

`Ortsname oder Adresse`

## Prerequisite

Keine – MUSS vor create/update mit Location-Feldern laufen
