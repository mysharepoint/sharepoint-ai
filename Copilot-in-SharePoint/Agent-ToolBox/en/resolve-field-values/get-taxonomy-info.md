# get_taxonomy_info

## Purpose (EN)

Resolves taxonomy terms for SharePoint managed metadata fields.

## Zweck (DE)

Löst Taxonomy-Begriffe für SharePoint-Managed-Metadata-Felder auf.

## Use Case (EN)

Get correct term values for managed metadata.

## Anwendung (DE)

Korrekte Termwerte für verwaltete Metadaten ermitteln.

## Example (EN)

> Resolve the term Wind Energy for the taxonomy field Industry.

## Beispiel (DE)

> Löse den Term Windenergie für das Taxonomie-Feld Branche auf.

## Prompt Template (EN)

> Resolve [term] for the taxonomy field [field name].

## Prompt-Vorlage (DE)

> Löse [Term] für das Taxonomie-Feld [Feldname] auf.

## Key Parameters

`Taxonomiefeld, Suchbegriff`

## Prerequisite

Keine – MUSS vor create/update mit Taxonomie-Feldern laufen
