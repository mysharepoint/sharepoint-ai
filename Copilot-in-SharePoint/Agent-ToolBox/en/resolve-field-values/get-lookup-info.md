# get_lookup_info

## Purpose (EN)

Resolves lookup field values into correct SharePoint format.

## Zweck (DE)

Löst Lookup-Feldwerte in das korrekte SharePoint-Format auf.

## Use Case (EN)

Get correct reference values for linked lists.

## Anwendung (DE)

Korrekte Referenzwerte für verknüpfte Listen ermitteln.

## Example (EN)

> Resolve Project Alpha for the lookup field Project.

## Beispiel (DE)

> Löse den Wert Projekt Alpha für das Lookup-Feld Projekt auf.

## Prompt Template (EN)

> Resolve [value] for the lookup field [field name].

## Prompt-Vorlage (DE)

> Löse [Wert] für das Lookup-Feld [Feldname] auf.

## Key Parameters

`Lookup-Feld, Suchwert`

## Prerequisite

Keine – MUSS vor create/update mit Lookup-Feldern laufen
