# get_datetime_info

## Purpose (EN)

Formats date/time values for SharePoint DateTime fields.

## Zweck (DE)

Formatiert Datums-/Zeitwerte für SharePoint-DateTime-Felder.

## Use Case (EN)

Generate correct date formats for list items.

## Anwendung (DE)

Korrekte Datumsformate für Listeneinträge erzeugen.

## Example (EN)

> Format June 15, 2026 for a DateTime field.

## Beispiel (DE)

> Formatiere 15. Juni 2026 für ein DateTime-Feld.

## Prompt Template (EN)

> Format [date] for a DateTime field.

## Prompt-Vorlage (DE)

> Formatiere [Datum] für ein DateTime-Feld.

## Key Parameters

`Datumswerte (optional)`

## Prerequisite

Keine – MUSS vor create/update mit DateTime-Feldern laufen
